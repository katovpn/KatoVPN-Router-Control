# KatoVPN Поддержка для Android

Приложение открывает временный SSH-доступ для поддержки OpenWrt и ImmortalWrt. Подключитесь к Wi-Fi нужного роутера и укажите его локальный IPv4, SSH-порт, логин и пароль. После подтверждения отпечатка SSH-ключа приложение покажет код и срок действия доступа. Скопируйте данные и передайте их сотруднику поддержки.

Поддержка получает административный доступ на срок до часа. Остановить подключение можно в приложении или через уведомление. После перезагрузки роутера или обрыва связи приложение пытается восстановить доступ по тому же коду до пяти минут в пределах исходного часа. Телефон должен снова подключиться к Wi-Fi нужного роутера. При повторном подключении приложение сверяет его SSH-отпечаток. После завершения процесса приложения требуется открыть новый доступ. Сервер ограничивает время сеанса, а на роутере cron удаляет временный ключ. Для подключения нужны Dropbear, активный cron и команда `timeout`.

Приложение не сохраняет пароль в настройках, журналах или резервных копиях. Пароль используется только для локальной SSH-аутентификации. В буфер обмена по нажатию кнопки попадают только данные поддержки.

## Сборка

Android 10 и новее. Для сборки на Windows нужны JDK 21, Android SDK Platform 35 и Build Tools 35.0.0. Скрипт скачивает JSch 2.28.8 и Bouncy Castle 1.87 из Maven Central, сверяет SHA-256 и запускает тесты проверки адреса, срока доступа и восстановления связи. Используйте отдельное хранилище ключей для этого приложения с псевдонимом `katovpn-support`. Пароль передаётся через переменную окружения `KATO_ANDROID_SIGN_PASSWORD`.

```powershell
./tools/android-support/build.ps1 -Sdk $env:ANDROID_HOME -Jdk $env:JAVA_HOME -Keystore $env:KATO_ANDROID_KEYSTORE
```

Первая сборка предназначена для тестирования. На время проверки используйте один клиент поддержки на роутер. Перед широким распространением проверьте на физическом телефоне запуск на домашнем Wi-Fi, работу с погашенным экраном, ручное завершение, обрыв Wi-Fi и удаление ключа по таймеру.
