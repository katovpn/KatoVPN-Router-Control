# KatoVPN Поддержка для Android

Приложение открывает временный SSH-доступ для поддержки OpenWrt и ImmortalWrt. Подключитесь к Wi-Fi нужного роутера и укажите его локальный IPv4, SSH-порт, логин и пароль. После подтверждения отпечатка SSH-ключа приложение покажет код и срок действия доступа. Скопируйте данные и передайте их сотруднику поддержки.

Поддержка получает административный доступ на срок до часа. Остановить подключение можно в приложении или через уведомление. После перезагрузки, обновления прошивки или обрыва связи приложение пытается восстановить доступ по тому же коду и порту до исходного срока завершения. Телефон должен снова подключиться к Wi-Fi нужного роутера. Если его SSH-отпечаток не изменился, приложение проверит и при необходимости восстановит временный ключ и его автоудаление. Если отпечаток изменился, приложение не передаст пароль и не откроет туннель. После завершения процесса приложения требуется открыть новый доступ. Сервер ограничивает время сеанса, а на роутере cron удаляет временный ключ. Для подключения нужны Dropbear, активный cron и команда `timeout`.

Приложение держит пароль только в памяти до выхода с роутера или завершения доступа. Пароль используется только для локальной SSH-аутентификации на этом роутере; он не записывается в настройки, журналы или резервные копии. В буфер обмена по нажатию кнопки попадают только данные поддержки.

## Сборка

Android 10 и новее. Для сборки на Windows нужны JDK 21, Android SDK Platform 35 и Build Tools 35.0.0. Скрипт скачивает JSch 2.28.8 и Bouncy Castle 1.87 из Maven Central, сверяет SHA-256 и запускает JVM-тесты адреса, срока доступа, восстановления состояния и проверки SSH-баннера. Для обновления установленного приложения используйте исходное хранилище ключей с псевдонимом `katovpn-support`. Пароль передаётся через переменную окружения `KATO_ANDROID_SIGN_PASSWORD`. Результат: `KatoVPN-Router-Support-v0.1.3-preview.apk`.

```powershell
./tools/android-support/build.ps1 -Sdk $env:ANDROID_HOME -Jdk $env:JAVA_HOME -Keystore $env:KATO_ANDROID_KEYSTORE
```

Для расширенной локальной проверки можно передать `-TestShell` (путь к `sh.exe` из Git для Windows) и `-TestPython` (путь к Python с Paramiko). Они включают выполнение команд на временной файловой структуре и проверку реальной SSH-аутентификации на loopback. Ни один тест не подключается к реальному роутеру.

На время проверки используйте один клиент поддержки на роутер. Перед широким распространением проверьте на физическом телефоне запуск на домашнем Wi-Fi, работу с погашенным экраном, ручное завершение, обрыв Wi-Fi, восстановление после обновления прошивки и удаление ключа по таймеру.
